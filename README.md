# MedAudioLab

Профессиональное приложение для записи, хранения и глубокого спектрального анализа звуковых и ультразвуковых сигналов.

## Структура проекта

Проект построен по модульному принципу. Логика разделена на пакеты для обеспечения чистоты кода и удобства поддержки.

```text
med_audio_lab/
├── __main__.py               # Точка входа в приложение
├── backend/                  # Бизнес-логика, БД и работа с диском
├── dsp/                      # Цифровая обработка сигналов (математика)
├── gui/                      # Фронтенд (интерфейс и отрисовка графиков)
├── hardware/                 # Захват данных (микрофоны, COM-порты)
└── utils/                    # Вспомогательные функции и конвертеры

```

## Описание пакетов

### 1. `backend/` — Бизнес-логика

Отвечает за "мозги" приложения.

* `storage.py`: Управление SQLite базой данных (`med_audio_lab.sqlite3`), настройки приложения, сохранение записей и генерация отчетов в формате CSV.
* `analysis.py`: Оркестратор расчетов. Вызывает математические функции из `dsp` и преобразует сырые данные (нормализация, фильтрация, вычисление метрик).

### 2. `dsp/` — Цифровая обработка сигналов (DSP)

Пакет чистой математики без привязки к интерфейсу.

* `fourier.py`: FFT и STFT преобразования.
* `wavelet.py`: Непрерывное вейвлет-преобразование (CWT) с использованием вейвлета Морле.
* `scales.py`: Загрузка конфигураций частотных шкал для вейвлетов.

### 3. `gui/` — Графический интерфейс

* `app.py`: Главное окно приложения (библиотека `tkinter`). Управляет жизненным циклом программы и связывает все модули вместе.
* `plotting.py`: Обертки над `matplotlib` для отрисовки графиков внутри виджетов Tkinter (`CanvasPlot`).

### 4. `hardware/` — Захват данных

Абстракция над источниками сигнала.

* `microphone.py`: Работа с аудиоустройствами через `sounddevice`.
* `serial_port.py`: Чтение бинарных и текстовых данных с внешних устройств (например, STM32) через `pyserial`. Включает встроенные механизмы коррекции сдвига байтов и DC Offset.

### 5. `utils/` — Вспомогательные утилиты

* `io.py`: Универсальный загрузчик WAV файлов (`soundfile`/`scipy`).
* `txt_converter.py`: Утилита для конвертации текстовых массивов данных в аудиоформат.
* `helpers.py`: Вспомогательные функции (например, `slugify` для имен файлов).

## Запуск

Для запуска проекта из корневой директории используйте команду:

```bash
python -m med_audio_lab

```

## Требования

Библиотеки для анализа и обработки данных:
`numpy`, `scipy`, `matplotlib`, `sounddevice`, `soundfile`, `pyserial`.
